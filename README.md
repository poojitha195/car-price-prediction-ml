# Car Price Prediction with Machine Learning

## Objective
Predict car selling prices using machine learning regression techniques.

## Dataset
- car data.csv

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Features
- Data Cleaning
- Feature Engineering
- Data Visualization
- Regression Model Training
- Model Evaluation

## Dataset Columns
- Car_Name
- Year
- Selling_Price
- Present_Price
- Driven_kms
- Fuel_Type
- Selling_type
- Transmission
- Owner

## Conclusion
The project uses machine learning to estimate car prices based on vehicle characteristics and market-related factors.
